# Narrative Radar

Outil multi-chain (Solana, BNB Chain, Robinhood Chain) d'intelligence narrative pour memecoins :
détection des narratifs sur X, mesure de la hype (rising / peaking / fading), confirmation on-chain
et smart money, décision compacte (ENTER / SCALE / EXIT / IGNORE), suivi de la performance depuis le
first alert, et boucle d'amélioration nocturne avec validation humaine.

- Architecture, priorisation MVP → V1 → V2, agents, format de l'état compact, APIs, interface,
  risques et ordre de construction : [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
